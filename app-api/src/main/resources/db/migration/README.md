# Flyway 마이그레이션

ERD 확정(9/1) 후 `V1__init.sql` 부터 여기에 넣는다.

## 규칙
- 파일명: `V{번호}__{설명}.sql` (예: `V2__add_clothes_attribute.sql`)
- **이미 머지된 V 파일은 절대 수정하지 않는다.** 바꾸려면 새 V 파일을 추가한다.
- 번호가 겹치면 머지 시 충돌한다. **V 파일을 만들기 전에 회의에서 번호를 공유할 것** (3차 회의 결정)
- 식별자는 snake_case, 테이블은 `대분류_의미있는이름_tb`
- 문자셋은 컨테이너 기본값이 `utf8mb4` 라 DDL 에 따로 쓰지 않아도 된다
